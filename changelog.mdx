<Update label="2026-05-20" tags={["Pivot"]} description="Week of May 18">
  ## Archer is now a rewards platform

  We rebuilt Archer as a developer-first rewards platform. The old payouts, smart wallet, and on-/off-ramp surfaces are retired. The new product centers on three primitives:

  - **Rewards** — rules created via `/agent` that describe a trigger and a reward in plain English.
  - **Events** — JSON payloads `POST`ed to a reward's unique webhook URL (or fired from a Slack slash command).
  - **Agent runtime** — the Lambda that resolves each event to its reward and runs it idempotently.

  See the new [Introduction](/introduction) and [Quickstart](/quickstart). Existing payout, smart wallet, paying limits, and fund/off-ramp docs have been removed.
</Update>

<Update label="2026-05-13" tags={["Internal"]} description="Week of May 11">
  ## Agent runtime stabilizes

  The agent Lambda now resolves event-queue messages directly via `Agent.discriminant` — no LLM classification, no Slack-team fallback. Messages without a resolvable discriminant are acknowledged and dropped. Reward execution is idempotent per `(event_id, agent_id)`.
</Update>

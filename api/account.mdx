---
title: "Account & team API"
description: "Endpoints for reading the caller's account, managing workspace settings, team members, Slack, and notifications."
---

Base URL: `https://api.archermoney.com`
All endpoints require an Auth0 access token. See [Authentication](/api/authentication).

## Account

```
GET /account
```

Returns the caller's account and profile, including workspace metadata:

```json
{
  "account": {
    "id": "acc_...",
    "workspace_name": "Acme Inc.",
    "sender_display_name": "Acme Rewards",
    "reply_to_email": "rewards@acme.com",
    "business_address": {
      "line1": "...",
      "city": "...",
      "region": "...",
      "postal_code": "...",
      "country": "US"
    }
  },
  "user": { "id": "auth0|...", "email": "...", "name": "...", "role": "owner" }
}
```

```
POST /account
```

Creates or resumes a Business account for the caller's Auth0 subject. Used on first sign-in. May seed verified Auth0 email and name claims.

`PATCH /account` updates workspace and profile fields.

## Team members

```
GET /team/members
```

Returns active users on the account. Available to all roles.

```
PATCH /team/members?user_id={id}
```

**Required roles**: owner, admin.

Update a user's `role` (`owner`, `admin`, `approver`, `member`) or other editable fields.

## Team invites

```
POST /team/invites
```

**Required roles**: owner, admin.

```json
{ "email": "jordan@example.com", "role": "admin" }
```

Creates a pending user row. The invitee becomes active on first Auth0 sign-in with the matching verified email.

## Slack workspace

```
GET /slack_workspace
POST /slack_workspace
PATCH /slack_workspace
DELETE /slack_workspace
```

**Required roles**: owner, admin (for writes); all roles can read.

`POST` exchanges an OAuth code from Slack and persists the workspace. See [Connect Slack](/guides/connect-slack).

## Notification settings

```
GET /notification_settings
PATCH /notification_settings
```

**Required roles**: owner, admin (for writes); all roles can read.

Returns and updates per-account notification preferences. Notification persistence and email delivery are implemented in the notification dispatcher worker.

## Health

```
GET /health
```

Public, unauthenticated. Used by the Archer health canary; you can hit it from monitoring tools.

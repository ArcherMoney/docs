---
title: "Activity & approvals API"
description: "Read reward fulfillment history, export activity to CSV, and act on the goods-order approval queue."
---

Base URL: `https://api.archermoney.com`
All endpoints require an Auth0 access token. See [Authentication](/api/authentication).

## List activity

```
GET /activity
```

Returns reward fulfillments grouped by day. Only `delivered` (fulfilled) and `pending` (pending approval) rows are surfaced.

Query parameters:

| Param | Type | Description |
|---|---|---|
| `start_date` | ISO 8601 date | Lower bound (inclusive). |
| `end_date` | ISO 8601 date | Upper bound (inclusive). |
| `status` | `delivered` \| `pending` | Filter by status. |

Response:

```json
{
  "days": [
    {
      "day": "2026-05-20",
      "rows": [
        {
          "id": "ord_...",
          "agent_id": "5b2a...",
          "agent_name": "Referral payout",
          "status": "delivered",
          "time": "2026-05-20T17:55:00Z",
          "recipient": "alice@example.com",
          "amount": 25.0
        }
      ]
    }
  ]
}
```

## Export activity

```
GET /activity/export
```

Same filters as `/activity`. Returns a CSV file (`Content-Type: text/csv`) with one row per activity entry. Useful for accounting and compliance archives.

## Goods orders

Internal endpoints used by the Archer ordering portal. They use `x-internal-key`, not Auth0.

| Method + path | Purpose |
|---|---|
| `GET /goods_order` | Read goods orders (ordering portal). |
| `PATCH /goods_order` | Update an order (pricing, fields). |
| `POST /goods_order/purchasing` | Mark an order as purchased and provision fulfillment. |

Don't call these from product integrations — use `/activity` and `/goods_order/approvals` instead.

## Approval queue

```
GET /goods_order/approvals
```

**Required roles**: owner, admin, approver.

Returns orders in `pending_approval` state, serialized with `status: "pending"`.

```json
{
  "orders": [
    {
      "id": "ord_...",
      "agent_name": "Office swag",
      "category": "office",
      "recipient": "jordan@example.com",
      "item": "YETI Tumbler",
      "quoted_price": 35.0,
      "status": "pending",
      "requested_at": "2026-05-20T15:00:00Z"
    }
  ]
}
```

### Approve or decline

```
PATCH /goods_order/approvals
```

**Required roles**: owner, admin, approver.

```json
{
  "order_id": "ord_...",
  "decision": "approve"
}
```

| `decision` | Effect |
|---|---|
| `approve` | Order moves to fulfillment; appears as `delivered` once shipped or settled. |
| `decline` | Order is hidden from the approval queue and from `/activity`. |

---
title: "Rewards API"
description: "Manage Archer reward rules through the /agent endpoints: list, filter, create, update, pause, and archive webhook- or Slack-triggered rewards."
---

Base URL: `https://api.archermoney.com`
All endpoints require an Auth0 access token. See [Authentication](/api/authentication).

## List rewards

```
GET /agent
```

Query parameters:

| Param | Type | Description |
|---|---|---|
| `agent_id` | string | Return a single reward by id. |
| `status` | `active` \| `paused` | Filter by status. |
| `category` | `office` \| `customer` \| `partner` | Filter by category. |

**Response** (list):

```json
{
  "agents": [
    {
      "id": "5b2a...",
      "name": "Referral payout",
      "logic": "When a referred user...",
      "category": "partner",
      "trigger_kind": "webhook",
      "trigger": "Webhook",
      "status": "active",
      "webhook_token": "0xabc...",
      "webhook_url": "https://api.archermoney.com/events/0xabc...",
      "created_at": "2026-05-20T10:00:00Z",
      "is_archived": false,
      "sent_today": 3,
      "total_sent": 27,
      "last_event": "2026-05-20T17:55:00Z",
      "tags": [{ "category": "agent_category", "slug": "partner", "label": "Partner Gift" }]
    }
  ],
  "count": 1
}
```

When `agent_id` is supplied, the response is the single agent object (no `agents`/`count` wrapper).

## Create a reward

```
POST /agent
```

**Required roles**: owner, admin.

**Body**:

```json
{
  "name": "Referral payout",
  "logic": "When a referred user completes onboarding, pay the referrer $25",
  "category": "partner",
  "trigger_kind": "webhook",
  "status": "active"
}
```

| Field | Type | Required | Notes |
|---|---|---|---|
| `name` | string | yes | Non-empty. |
| `logic` | string | yes | Plain-English description of the trigger and reward. |
| `category` | string | yes | `office`, `customer`, or `partner`. |
| `trigger_kind` | string | no | `webhook` (default) or `slack`. |
| `status` | string | no | `active` (default) or `paused`. |

**Responses**:

- `201 Created` — returns the new reward plus `"message": "Agent created successfully"`.
- `400 Bad Request` — invalid payload.
- `409 Conflict` — `trigger_kind: "slack"` and an active Slack reward already exists.

## Update a reward

```
PATCH /agent?agent_id={id}
```

**Required roles**: owner, admin.

**Body** — any subset of `name`, `logic`, `category`, `status`:

```json
{ "status": "paused" }
```

Returns the updated reward. `webhook_url` does not change.

## Archive a reward

```
DELETE /agent?agent_id={id}
```

**Required roles**: owner, admin.

Sets `is_archived: true`. The reward stops accepting events at the agent runtime and disappears from list responses. There is no un-archive endpoint — recreate the reward if you need it back.

## Errors

| Status | Body | Cause |
|---|---|---|
| `400` | `{ "error": "..." }` | Invalid JSON, missing fields, invalid enum. |
| `401` | (Auth0 error) | Missing or invalid access token. |
| `403` | RBAC denial | Caller lacks required role. |
| `404` | `{ "error": "Agent not found" }` | Wrong `agent_id` or already archived. |
| `409` | `{ "error": "An active Slack agent already exists." }` | Slack uniqueness violation. |
| `500` | `{ "error": "Internal server error" }` | Unexpected. Check Archer status. |

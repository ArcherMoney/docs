Import from `@archermoney/sdk`.

```ts
import { ArcherWorkerClient, ArcherApiError } from "@archermoney/sdk";
```

## Constructor

```ts
new ArcherWorkerClient(config: ArcherSdkConfig)
```

### `ArcherSdkConfig`

| Field | Type | Notes |
| --- | --- | --- |
| `apiBaseUrl` | `string` | Archer API URL. Trailing slashes are trimmed. |
| `tenantId` | `string` | Assigned by Archer. |
| `getSubjectToken` | `() => string \| Promise<string>` | Returns a fresh subject JWT for the current end user. |
| `fetch` | `typeof fetch` (optional) | Override the global `fetch`, useful for Node \< 18 or test doubles. |
| `tokenTtlSkewMs` | `number` (optional) | How early to refresh before expiry. Default `30_000`. |

## Session management

### `exchangeToken()`

```ts
exchangeToken(): Promise<ArcherTokenExchangeResponse>
```

Forces a token exchange and caches the result. You rarely call this directly.

### `getAccessToken()`

```ts
getAccessToken(): Promise<string>
```

Returns a valid session token, refreshing if needed.

### `clearSession()`

```ts
clearSession(): void
```

Drops the cached session token. Call on sign-out.

## Account and history

### `getAccount()`

```ts
getAccount(): Promise<ArcherAccount>
```

Returns the Archer account for the current subject, including `smart_wallet_address` and `user_eoa_address`.

### `getTransactionHistory(params)`

```ts
getTransactionHistory(params?: {
  limit?: number;
  cursor?: string | number;
  fromTs?: number;
  toTs?: number;
}): Promise<TransactionHistoryResponse>
```

Cursor-paginated. Timestamps are Unix seconds.

### `getOfframpHistory()`

```ts
getOfframpHistory(): Promise<{ history: OfframpHistoryRecord[] }>
```

Bridge cash-out records.

## On-chain balance

### `getUsdcBalance(options)`

```ts
getUsdcBalance(options: {
  rpcUrl: string;
  usdcAddress: Address;
  chainId?: 8453 | 84532;
  decimals?: number;
}): Promise<number>
```

Reads USDC `balanceOf(smart_wallet_address)` via viem. Defaults: `chainId` picks between Base and Base Sepolia; `decimals` defaults to `6`.

## Wallet intents

### `prepareWalletIntent(intent)`

```ts
prepareWalletIntent(intent: WalletIntent): Promise<PreparedIntentResult>
```

Asks Archer to build a user operation for the intent.

### `submitWalletIntent(intent, signed)`

```ts
submitWalletIntent(
  intent: WalletIntent,
  signed: SignedPayload,
): Promise<SignedWalletResult>
```

Relays a signed user operation. Returns `tx_hash` and `user_operation_hash`.

### `prepareCashOut(params)`

```ts
prepareCashOut(params: {
  amount: string;         // decimal string, e.g. "25.00"
  usdcAddress: string;
  externalAccountId?: string;
}): Promise<PreparedCashOut>
```

Convenience wrapper: ensures a liquidation address, builds an `erc20_transfer` intent, and calls `prepareWalletIntent`.

## Errors

All methods throw `ArcherApiError` for non-2xx responses. See [Errors](/reference/errors) for status-code semantics.

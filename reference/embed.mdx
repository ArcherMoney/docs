Import from `@archermoney/sdk/embed`.

```ts
import {
  mountArcherWorkerWidget,
  ArcherWorkerView,
  type MountedArcherWorkerWidget,
} from "@archermoney/sdk/embed";
```

## `mountArcherWorkerWidget(target, props)`

```ts
function mountArcherWorkerWidget(
  target: Element | string,
  props: ArcherWorkerViewProps,
): MountedArcherWorkerWidget;

interface MountedArcherWorkerWidget {
  unmount: () => void;
}
```

- `target` can be a CSS selector or a DOM `Element`.
- `props` is identical to [`ArcherWorkerView` props](/reference/react#archerworkerview).
- Returns a handle; call `unmount()` to tear down the React root cleanly.

Throws `Error("Archer widget target was not found")` if the selector resolves to `null`.

## `window.ArcherWorkerWidget`

When the embed entry loads in a browser, it assigns:

```ts
window.ArcherWorkerWidget = {
  mount: mountArcherWorkerWidget,
};
```

That lets script-tag hosts call `window.ArcherWorkerWidget.mount(...)` without a module import.

## Re-exports

`ArcherWorkerView` is re-exported for convenience so hosts that use a bundler can pull the component directly from the embed entry.

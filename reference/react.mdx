Import from `@archermoney/sdk/react`.

```ts
import {
  ArcherWorkerProvider,
  useArcherWorker,
  ArcherWorkerView,
  type ArcherWorkerState,
  type ArcherWorkerProviderProps,
  type ArcherWorkerViewProps,
} from "@archermoney/sdk/react";
```

## `<ArcherWorkerProvider>`

```ts
interface ArcherWorkerProviderProps {
  config: ArcherSdkConfig;
  balance?: GetBalanceOptions;
  children: ReactNode;
}
```

Creates an `ArcherWorkerClient`, calls `getAccount`, `getTransactionHistory({ limit: 100 })`, `getOfframpHistory`, `listExternalAccounts`, and (if `balance` is provided) `getUsdcBalance` in parallel on mount, and re-runs whenever `config` or `balance` change.

Errors from the individual off-ramp, external-accounts, and balance calls are caught and surfaced as empty defaults. A fatal error from `getAccount` or `getTransactionHistory` sets `state.error`.

## `useArcherWorker()`

```ts
function useArcherWorker(): ArcherWorkerState

interface ArcherWorkerState {
  client: ArcherWorkerClient;
  account: ArcherAccount | null;
  balance: number | null;
  balanceSeries: BalancePoint[];
  transactions: TransactionHistoryItem[];
  offrampHistory: OfframpHistoryRecord[];
  externalAccounts: BridgeExternalAccount[];
  loading: boolean;
  error: Error | null;
  refresh: () => Promise<void>;
}
```

Throws if called outside an `<ArcherWorkerProvider>`.

## `<ArcherWorkerView>`

```ts
interface ArcherWorkerViewProps {
  config: ArcherSdkConfig;
  balance?: GetBalanceOptions;
  usdcAddress?: string;
  onAuthorizeCashOut?: (prepared: PreparedCashOut) => Promise<SignedPayload>;
}
```

Renders a self-contained UI: hero balance, balance-over-time chart, latest transactions, and a cash-out panel. Internally wraps its children in `<ArcherWorkerProvider>`.

- `usdcAddress` is required for the cash-out panel to submit a transfer.
- `onAuthorizeCashOut` receives the `PreparedCashOut` and must return a `SignedPayload`. Without it, the panel refuses to submit.

## `GetBalanceOptions`

```ts
interface GetBalanceOptions {
  rpcUrl: string;
  usdcAddress: Address;
  chainId?: 8453 | 84532;
  decimals?: number;
}
```

Same shape used by `ArcherWorkerClient.getUsdcBalance()`.

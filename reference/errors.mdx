All non-2xx responses from the Archer API surface as `ArcherApiError`.

```ts
import { ArcherApiError } from "@archermoney/sdk";

class ArcherApiError extends Error {
  readonly status: number;
  readonly body: unknown;
}
```

- `message` is either the `error` field from the response body or a generic "Archer API request failed with N".
- `body` is the parsed JSON body (or `null` if the response had no body).
- `status` is the HTTP status code.

## Handling

```ts
try {
  await client.getAccount();
} catch (err) {
  if (err instanceof ArcherApiError) {
    if (err.status === 401) {
      client.clearSession();
      // prompt sign-in / mint a fresh subject token
    } else if (err.status === 429) {
      // back off and retry
    } else {
      console.error(err.message, err.body);
    }
    return;
  }
  throw err;
}
```

## Status-code cheat sheet

| Status | Typical cause | Recovery |
| --- | --- | --- |
| `400` | Malformed request body, invalid intent, mutated `request_payload`. | Fix the request; do not retry unchanged. |
| `401` | Session token missing, expired, or subject token rejected. | `clearSession()` and retry so the SDK re-exchanges. |
| `403` | Tenant / issuer mismatch, or the signer is not authorized on the smart wallet. | Verify tenant configuration; check host signer. |
| `404` | Resource does not exist (account not yet provisioned, unknown external account id). | Poll or provision, then retry. |
| `409` | Conflicting state (for example, Bridge onboarding not complete). | Read the relevant status endpoint and reconcile. |
| `422` | Bridge or downstream provider rejected the request. | Inspect `body` for the underlying reason. |
| `429` | Rate limited. | Exponential backoff. |
| `5xx` | Archer or an upstream provider had an error. | Retry with backoff; report if persistent. |

## Non-API errors

The client also throws plain `Error`s for local misuse:

- `"apiBaseUrl is required"` — empty `apiBaseUrl` in `ArcherSdkConfig`.
- `"Worker smart wallet is not ready"` — `getUsdcBalance` called before the smart wallet is provisioned.
- `"Liquidation address is not ready"` — `prepareCashOut` called before Bridge onboarding completed.
- `"useArcherWorker must be used inside ArcherWorkerProvider"` — hook called outside its provider.
- `"Archer widget target was not found"` — embed selector did not resolve.

---
title: "Triggers"
description: "Webhook triggers connect Archer to your product or backend. Slack triggers let teammates fire rewards from chat."
---

A **trigger** is the channel that delivers events to an agent. Each agent picks one of two trigger kinds when it's created. You can't switch an existing agent between trigger kinds — create a new agent if you need the other.

## Webhook trigger

The default. Archer assigns each webhook agent its own URL on the **Agent** detail page:

```
https://api.archermoney.com/events/{webhook_token}
```

Your system `POST`s a JSON event to the URL and Archer fires the agent. No bearer token, no signature — the URL itself is the secret, so keep it out of client-side code and source control.

**Best for**: anything programmatic. CRMs, product backends, CI pipelines, marketing automation, internal tools.

See [Sending events](/developers/sending-events) for the request shape, idempotency, and retry guidance.

## Slack trigger

Connect Slack from the **Integrations** page, then create one agent with **Slack** as its trigger. After install, a teammate types:

```
/archer Send a YETI tumbler to jordan@acme.com
```

Archer verifies the Slack request, routes it to your Slack agent, and fires the reward. Office Order Slack agents land in the Approvals queue; Customer and Partner Gift Slack agents send immediately.

**Best for**: ad-hoc requests from teammates — new-hire swag, customer thank-yous, last-minute gifts.

You can have **at most one active Slack-triggered agent per workspace**. Pause or archive the existing Slack agent first if you need to replace it.

## Pausing a trigger

Set an agent to **Paused** from its detail page (the "Agent is active" toggle) to stop processing without losing the webhook URL or Slack binding. Events received while paused are accepted and silently dropped — they will not be replayed when you reactivate the agent.

## Which trigger should I use?

| Signal source | Trigger |
|---|---|
| Your backend / product code | Webhook |
| Your CRM or sales tool | Webhook |
| CI pipeline event | Webhook |
| A teammate typing in Slack | Slack |
| A marketing automation step | Webhook |
| One-off office order | Slack |

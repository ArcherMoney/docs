title: "Agents: natural-language reward automations"

---

An **agent** is a reward rule. Each agent describes — in plain English — when a reward should fire and what should happen. Every reward Archer sends is the output of an agent.

## What an agent looks like

When you create an agent in the dashboard, you fill out five fields:

| Field | What it means |
|---|---|
| **Name** | Internal label, shown in Agents, Activity, and Approvals. |
| **Category** | `Office Order`, `Customer Gift`, or `Partner Gift`. Decides the fulfillment path. See [Categories](/concepts/categories). |
| **Logic** | A one- or two-clause plain-English description of the trigger and the reward. Archer uses this to match incoming events. |
| **Trigger** | `Webhook`. Decides how events reach the agent. See [Triggers](/concepts/triggers). |
| **Status** | `Active` or `Paused`. Paused agents accept events at the door but produce no rewards. |

You can also configure email and form branding per agent — subject, body, primary color, logo, and whether to show "Powered by Archer".

## How agents fire

<Steps>
  <Step title="Event arrives">
    Your system `POST`s a JSON event to the agent's webhook URL.
  </Step>
  <Step title="Agent matches">
    Archer routes the event directly to the agent that owns the webhook URL. There's no fuzzy classification across agents.
  </Step>
  <Step title="Reward sends">
    Customer Gift and Partner Gift rewards send immediately. Office Orders enter the **Approvals** queue first.
  </Step>
  <Step title="Activity updates">
    The reward shows up on the **Activity** page as `pending` (waiting on approval) or `delivered` (shipped or settled).
  </Step>
</Steps>

## Per-agent metrics

The agent detail page surfaces:

- **Sent today / this week / total sent** — how many rewards this agent has fired.
- **Last event** — when the agent most recently ran.
- **Recent activity** — a small feed of recent fulfillments, linked into the full Activity page.

## Pausing and archiving

- **Pause** an agent to temporarily stop it without losing its webhook URL or branding. Toggle it back to active any time. Events received while paused are accepted and silently dropped.
- **Archive** an agent (via delete) when you no longer need it. The webhook URL stops producing rewards. Archived agents are hidden from the Agents list and cannot be restored — create a new agent if you need the same rule back.

## How many agents can I create?

Webhook agents have no limit — create as many as you need, one per use case (onboarding gift, referral payout, milestone reward, and so on).

Your workspace's business address is part of the sender information Archer keeps on file alongside the workspace name, sender display name, and reply-to email. Set it once from **Settings → General** so it's available across compliance records and recipient-facing materials.

## When to use this

Add or update your business address whenever:

- You first set up an Archer workspace.
- Your company moves or registers a new entity.
- You need a complete address on file for compliance and audit purposes.

## Update the address

<Steps>
  <Step title="Open General settings">
    Select **Settings → General** from the left sidebar.
  </Step>
  <Step title="Open the address modal">
    Find the **Business address** field. If no address is saved yet, it shows **Not set**. Click **Edit** to the right of the field.
  </Step>
  <Step title="Fill in the address">
    Enter the street address, optional second line (suite, floor, or unit), city, state or province, ZIP or postal code, and country.
  </Step>
  <Step title="Save the address">
    Click **Save address**. The modal closes and the formatted address appears on the General tab.
  </Step>
</Steps>

## Address fields

| Field | Description |
|---|---|
| **Street address** | Line 1 of the address — for example, `123 Main St`. |
| **Address line 2** | Optional. Suite, floor, unit, or PO box. |
| **City** | The city the business is registered in. |
| **State / Province** | Two-letter US state code, or the full province name. |
| **ZIP / Postal code** | The postal code matching the city and state. |
| **Country** | Country name — `United States` by default. |

Click **Cancel** at any time to close the modal without saving. The address displays in a single line on the General tab using the format `line1, line2, city, state zip, country`, with empty fields skipped.

<Note>
  Business address sits next to **Workspace name**, **Sender display name**, and **Reply-to email** under General. Together these fields define how recipients see your organization on every reward Archer sends.
</Note>

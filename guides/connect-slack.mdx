---
title: "Connect Slack"
description: "Install the Archer Slack app via OAuth, create a Slack-triggered reward, and fire rewards from the /archer slash command in any channel."
---

Connecting Slack lets a teammate fire a reward by running a slash command. This is the right path for office orders, ad-hoc customer gifts, and any flow where the requester is a human rather than a system.

## Prerequisites

- A Slack workspace where you can install apps.
- Owner or Admin role on your Archer account.

## 1. Install the Slack app

In the Archer dashboard, open **Settings → Slack** and click **Install Slack**. You'll be redirected through Slack's OAuth flow:

1. Choose the workspace to install into.
2. Approve the requested scopes.
3. Slack returns you to Archer, which stores the workspace via `POST /slack_workspace`.

After install, `GET /slack_workspace` returns the workspace metadata:

```json
{
  "team_id": "T0123456",
  "team_name": "Acme Inc.",
  "installed_at": "2026-05-20T18:00:00Z",
  "url": "https://acme.slack.com"
}
```

## 2. Create a Slack-triggered reward

You can have at most one active Slack reward per account.

```bash
curl -X POST https://api.archermoney.com/agent \
  -H "Authorization: Bearer $ARCHER_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Office swag",
    "logic": "When a teammate runs /archer with a recipient and item, ship the item to their address",
    "category": "office",
    "trigger_kind": "slack"
  }'
```

If a Slack reward already exists you'll get:

```json
{ "error": "An active Slack agent already exists." }
```

Archive the existing reward (or change its `trigger_kind` to webhook) before creating a new one.

## 3. Fire the slash command

In any channel of the connected workspace, run the Archer slash command:

```
/archer Send a YETI tumbler to jordan@acme.com
```

The Slack ingest Lambda verifies the request signature and enqueues by `team_id`. The agent runtime resolves it to your single Slack-triggered reward and runs it. Office and customer rewards may land in the approval queue first.

## 4. Manage the install

- **Update** — `PATCH /slack_workspace` to refresh tokens or metadata.
- **Disconnect** — `DELETE /slack_workspace`. The Slack-triggered reward stops firing until you reinstall.

## Troubleshooting

| Symptom | Likely cause |
|---|---|
| Slash command returns silently | Slack reward is paused or archived. |
| `signature verification failed` in logs | Slack signing secret rotated; reinstall the app. |
| Command runs but nothing reaches Activity | Reward's `logic` doesn't match the message; check `EventRun` logs. |

The Integrations page is where you connect Archer to the other tools your team already uses. Slack is the first integration available. Once your workspace is connected, anyone in it can place an order with a slash command instead of opening the dashboard.

## When to use this

Use the Slack integration if your team kicks off rewards from chat, or if you want Slack-triggered agents to fire when a teammate runs the Archer order command.

## Prerequisites

- A role of `owner` or `admin`.
- Permission to install apps in the target Slack workspace.

## Connect your Slack workspace

<Steps>
  <Step title="Open Integrations">
    Select **Settings → Integrations** from the Archer dashboard.
  </Step>
  <Step title="Start the install">
    Under the **Slack** section, click **Add to Slack**. Archer redirects you to Slack's authorization screen.
  </Step>
  <Step title="Approve the requested scopes">
    Slack shows the scopes the Archer app requests — `chat:write`, `app_mentions:read`, `channels:join`, and `commands`. Select the workspace you want to connect and click **Allow**.
  </Step>
  <Step title="Confirm the connection">
    Slack redirects you back to Archer. The Slack section now shows your workspace with a green **Connected** badge.
  </Step>
</Steps>

Only one Slack workspace can be linked to an Archer account at a time. To swap workspaces, disconnect the current one first.

## Use the slash command

Once your workspace is connected, every member of that Slack workspace can run the order command in any channel or DM where the Archer app is installed:

| Command  | What it does                                                                 |
| -------- | ---------------------------------------------------------------------------- |
| `/order` | Opens a modal to place a goods order. See [Place an order from Slack](/guides/place-slack-order). |

Submitting the modal runs the order against the Archer account that installed the workspace, using the same approval rules as the dashboard.

```text Example
/order
```

If the command returns the message **"Slack Workspace not found. Open the Archer app, go to Settings → Integrations, and connect your Slack workspace."**, the workspace isn't linked yet — connect it from the Integrations page and try again.

## Disconnect your Slack workspace

To remove the integration, open **Settings → Integrations**, find the **Slack** section, and click **Delete** next to the connected workspace. Archer revokes the bot token and the slash command stops working immediately. You can reconnect at any time by clicking **Add to Slack** again.

---
title: "Invite team members"
description: "Invite teammates to your Archer account, assign owner, admin, approver, or member roles, and understand how Auth0 reconciles their identities."
---

Archer accounts support multiple users with role-based access control. Use the team endpoints to invite new members and assign roles.

## Roles

| Role | Can do |
|---|---|
| `owner` | Everything an admin can, plus account-level destructive actions. |
| `admin` | Create / update / delete rewards, install Slack, manage team, approve orders. |
| `approver` | Approve or decline goods orders. Read rewards and activity. |
| `member` | Read rewards, activity, team. |

## Send an invite

```bash
curl -X POST https://api.archermoney.com/team/invites \
  -H "Authorization: Bearer $ARCHER_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "email": "jordan@example.com",
    "role": "admin"
  }'
```

Archer creates a pending `User` row with the requested email and role. When the invitee signs in through Auth0 with that verified email, Archer reconciles the account and the role becomes active.

## List team members

```bash
curl "https://api.archermoney.com/team/members" \
  -H "Authorization: Bearer $ARCHER_TOKEN"
```

Returns active users on the account, including role and pending-status flags.

## Update a role

```bash
curl -X PATCH "https://api.archermoney.com/team/members?user_id=$USER_ID" \
  -H "Authorization: Bearer $ARCHER_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"role": "approver"}'
```

Only owners and admins can edit roles. Owners cannot demote themselves through the API.

## Auth0 reconciliation

Archer relies on Auth0 to verify identities. Invited users must sign in with the **same verified email** the invite was sent to. Auth0 account linking will fold matching identities (email/password, Google, Microsoft) into a single Archer user.

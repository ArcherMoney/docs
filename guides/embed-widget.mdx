`@archermoney/sdk/embed` renders the same UI as `<ArcherWorkerView />`, but exposes it as a plain function you can call from any JavaScript host: a static site, a server-rendered template, or a non-React SPA.

## Mount from a bundler

```ts
import { mountArcherWorkerWidget } from "@archermoney/sdk/embed";

const widget = mountArcherWorkerWidget("#archer-root", {
  config: {
    apiBaseUrl: "https://api.archermoney.com",
    tenantId: "your-tenant-id",
    getSubjectToken: fetchSubjectToken,
  },
  balance: {
    rpcUrl: "https://mainnet.base.org",
    usdcAddress: "0x833589fCD6eDb6E08f4c7C32D4f71b54bdA02913",
    chainId: 8453,
  },
  usdcAddress: "0x833589fCD6eDb6E08f4c7C32D4f71b54bdA02913",
  signAuthorization: async (requestPayload) => signWithHostWallet(requestPayload),
});

// Later, when the user navigates away:
widget.unmount();
```

The target can be a CSS selector or an existing `Element`.

## Mount from a script tag

When the embed entry is loaded in a browser, it also attaches to `window` so plain HTML pages can use it without a bundler.

```html
<div id="archer-root"></div>
<script type="module">
  import "https://cdn.example.com/@archermoney/sdk/embed.js";

  window.ArcherWorkerWidget.mount("#archer-root", {
    config: {
      apiBaseUrl: "https://api.archermoney.com",
      tenantId: "your-tenant-id",
      getSubjectToken: () => fetch("/api/archer/token").then((r) => r.text()),
    },
  });
</script>
```

<Note>
  Host the built `embed.js` yourself, or from a CDN you control. Archer does not ship a public embed script URL.
</Note>

## Props

`mountArcherWorkerWidget(target, props)` accepts the same props as [`ArcherWorkerView`](/reference/react#archerworkerview):

- `config` (required) — `ArcherSdkConfig`.
- `balance` (optional) — pass to enable on-chain USDC balance display.
- `usdcAddress` (optional) — required to submit cash-outs.
- `signAuthorization` (optional) — `AuthorizationSigner` the widget calls to sign each authorization payload (delegation on first use, then user operations). See [Wallet authorization](/concepts/wallet-authorization).

## Cleanup

Call `widget.unmount()` on route change or when the container is removed. Failing to unmount leaks the React root that renders inside your target element.

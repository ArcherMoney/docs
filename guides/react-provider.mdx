`ArcherWorkerProvider` builds an `ArcherWorkerClient` for you, fetches account, balance, transactions, off-ramp history, and external accounts on mount, and exposes the result through the `useArcherWorker()` hook.

Use it when you want the Archer data model but your own UI.

## Wire the provider

```tsx App.tsx
import { ArcherWorkerProvider } from "@archermoney/sdk/react";

export function App({ children }) {
  return (
    <ArcherWorkerProvider
      config={{
        apiBaseUrl: "https://api.archermoney.com",
        tenantId: "your-tenant-id",
        getSubjectToken: fetchSubjectToken,
      }}
      balance={{
        rpcUrl: "https://mainnet.base.org",
        usdcAddress: "0x833589fCD6eDb6E08f4c7C32D4f71b54bdA02913",
        chainId: 8453,
      }}
    >
      {children}
    </ArcherWorkerProvider>
  );
}
```

The `balance` prop is optional. Omit it if you do not want the provider to read on-chain USDC balance for you.

## Read state

```tsx WorkerCard.tsx
import { useArcherWorker } from "@archermoney/sdk/react";

export function WorkerCard() {
  const { account, balance, transactions, loading, error, refresh } = useArcherWorker();

  if (loading) return <p>Loading…</p>;
  if (error) return <p>{error.message}</p>;

  return (
    <section>
      <h2>{account?.name ?? account?.email}</h2>
      <p>Balance: ${balance?.toFixed(2) ?? "--"}</p>
      <p>{transactions.length} transactions</p>
      <button onClick={() => refresh()}>Refresh</button>
    </section>
  );
}
```

## What the state contains

| Field | Type | Notes |
| --- | --- | --- |
| `client` | `ArcherWorkerClient` | Call directly for anything the provider does not expose. |
| `account` | `ArcherAccount \| null` | Includes the canonical `wallet_address`. |
| `balance` | `number \| null` | USDC balance, or `null` if the `balance` prop was omitted or the read failed. |
| `balanceSeries` | `BalancePoint[]` | Synthesised from `transactions`, ready to feed a chart. |
| `transactions` | `TransactionHistoryItem[]` | Latest 100 by default. |
| `offrampHistory` | `OfframpHistoryRecord[]` | Bridge cash-out records. |
| `externalAccounts` | `BridgeExternalAccount[]` | Payout destinations the user has added. |
| `loading`, `error`, `refresh()` |  | Standard async state, call `refresh()` after a cash-out. |

## Refresh after mutations

Any time you call the client directly (for example to submit a wallet intent), call `refresh()` afterwards so the provider re-fetches account and history data.

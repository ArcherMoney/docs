Event payouts are automated transfers tied to a named condition. When Archer's agent detects that the condition has been satisfied — for example, a sales rep closing a qualifying deal — it executes the payout automatically. You choose the source that triggers the agent, define the condition, and set the spending limits; Archer handles the rest.

## Choose a source

When you create a new payout, you first pick the source that delivers events to Archer's agent. Each agent listens to exactly one source, so events from one channel never trigger rules attached to the other.

| Source | When to use it |
|---|---|
| **Webhook** | Trigger payouts from any tool that can send an HTTP POST request — Zapier, Airtable, Stripe, internal scripts, or your own backend. |
| **Slack** | Trigger payouts from a Slack channel using the Archer ordering bot. Best for team-driven workflows where requests start as Slack messages. |

## Create a webhook-triggered payout

<Steps>
  <Step title="Go to Payouts">
    Select **Payouts** from the left sidebar.
  </Step>
  <Step title="Open the creation form">
    Click the **Create payout** button in the top-right corner. A modal will appear.
  </Step>
  <Step title="Select Webhook">
    On the **Create a new agent** screen, select **Webhook**.
  </Step>
  <Step title="Enter a name and condition">
    Type a short, descriptive label in the **Payout Name** field (for example, `Q1 Sales Bonus`). In the **Condition** field, describe the trigger event in plain language (for example, `Sales rep closes deal over $10,000`).
  </Step>
  <Step title="Set spending limits">
    Configure the maximum per payment, maximum per period, and number of transactions allowed per period. These limits are enforced on-chain by the ArcherAgentEndpoint contract. See [Paying Limits](/concepts/paying-limits) for details.
  </Step>
  <Step title="Create the agent">
    Click **Create agent**. Archer saves the agent and generates its unique webhook URL on the next screen.
  </Step>
  <Step title="Copy the webhook URL">
    On the final step, copy the webhook URL Archer generated for this agent. Paste it into your tool of choice as a webhook endpoint, or send HTTP POST requests to it directly from your own code.

    ```bash
    curl -X POST https://api.archermoney.com/event_payout/webhook/<your-agent-id> \
      -H "Content-Type: application/json" \
      -d '{"event": "Sales rep closes deal over $10,000", "amount": 500, "recipient": "alex@example.com"}'
    ```

    Click **Done** to return to the Payouts list. You can retrieve the webhook URL again at any time from the agent's detail page.
  </Step>
  <Step title="Send a test event">
    Trigger an event from your tool to confirm the agent receives and evaluates it.
  </Step>
</Steps>

## Create a Slack-triggered payout

<Steps>
  <Step title="Go to Payouts">
    Select **Payouts** from the left sidebar.
  </Step>
  <Step title="Open the creation form">
    Click **Create payout** in the top-right corner.
  </Step>
  <Step title="Select Slack">
    On the **Create a new agent** screen, select **Slack**. Archer creates a Slack ordering agent that listens for messages routed from the Archer Slack app.
  </Step>
  <Step title="Set spending limits">
    Configure the maximum per payment, maximum per period, and number of transactions allowed per period, then click **Continue**. Archer saves the agent and authorizes the on-chain rule in a single step.
  </Step>
</Steps>

<Note>
  Slack agents and webhook agents are scoped to their source. Slack agents only evaluate Slack messages, and webhook agents only evaluate webhook requests. This prevents cross-triggering between channels.
</Note>

## Managing your payouts

### Search

Use the search bar at the top of the Payouts page to filter by payout name or condition text. Results update as you type.

### Archive a payout

To remove a payout from your active list, click the archive icon in its row. Archived payouts are no longer evaluated by Archer's agent and will not trigger transfers.

### Restore an archived payout

Click **Archived Payouts** in the page header to open the archived payouts panel. Locate the payout you want to restore and click **Restore** — it will return to your active list immediately.

<Tip>
  You can suspend all active payouts at once by clicking the **Pause all payouts** button in the page header. This is useful when you need to temporarily halt incentive payouts across your entire account without archiving each one individually.
</Tip>

<Note>
  The condition you enter is a human-readable description, not code. Archer's agent reads it to determine when to execute the payout. Be as specific as possible — clear conditions reduce false positives and missed triggers.
</Note>
